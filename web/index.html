Böhm's language

The language, machine and compiler from Corrado Böhm's 1951 dissertation, running in your browser. Every statement is an assignment: ? → a reads a number, a → ? prints one, B → π continues at group B, and Ω → π stops. It is the same Rust program as the command line, compiled to WebAssembly.
